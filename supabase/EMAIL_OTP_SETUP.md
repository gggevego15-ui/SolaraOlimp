# Подтверждение рабочей почты учителей

Solara Olimp отправляет одноразовый шестизначный код через Resend. Edge Function уже содержит отправку, проверку кода и серверную блокировку заявки без подтверждённой почты.

## Однократная настройка администратора

1. Создай аккаунт в [Resend](https://resend.com/) и добавь домен, с которого будут отправляться письма.
2. В DNS домена добавь записи, которые покажет Resend, и дождись статуса **Verified**. Без проверенного домена письма могут не отправляться.
3. В Resend создай API key с разрешением отправлять письма.
4. Открой Supabase Dashboard → проект Solara Olimp → **Edge Functions** → **Secrets** (или Project Settings → Edge Function Secrets).
5. Добавь два секрета:
   - `RESEND_API_KEY` — API key из Resend.
   - `EMAIL_FROM` — отправитель на проверенном домене, например `Solara Olimp <noreply@mail.example.org>`. Замени пример на свой домен.
6. Убедись, что функция `olimp-api` активна. После сохранения секретов повторный деплой обычно не требуется.

Не добавляй API key в `index.html`, репозиторий GitHub, скриншоты или сообщения. Он должен существовать только в секретах Supabase.

## Как работает проверка

- Учитель вводит рабочую почту и запрашивает код.
- Код из 6 цифр действует 10 минут; повторная отправка ограничена интервалом в 60 секунд.
- После пяти неверных попыток потребуется запросить новый код.
- После проверки почты заявка отправляется на ручную проверку администрации.
- Сервер проверяет подтверждение повторно при создании заявки; нельзя обойти проверку простым изменением интерфейса.
- Таблица одноразовых кодов закрыта для публичных ролей RLS и хранит хеш, а не код в открытом виде.

## Проверка после настройки

1. Открой сайт и перейди в «Я учитель».
2. Введи доступную почту, затем нажми «Получить код».
3. Проверь входящие и папку «Спам», введи код и нажми «Подтвердить».
4. Заполни остальные поля и отправь заявку.
5. Если письмо не приходит, проверь в Resend статус домена и журнал отправки, затем проверь логи Edge Function в Supabase.

**Важно:** в коде приложения нет обходного режима. Пока `RESEND_API_KEY` и `EMAIL_FROM` не настроены, отправка вернёт сообщение о том, что почта не настроена, и заявка не сможет считаться подтверждённой.
